How the tensquads agents work together

One owner, one master agent and two specialist agents. Petra, the master, runs the plan and checks every piece of work. Machu does market research. Angkor builds and publishes the website. Nothing reaches the public without the owner saying yes.

Start and end Agent does the work Petra checks the work Owner decides

The agents

Petra

Master agent · runs inside the tensquads app
  • Reads the owner's first message: the business name, its items and prices, and an optional city.
  • Sends each task to the right agent and checks every result in code before it moves on.
  • Writes the brief from Machu's report. The model writes the words only. Items and prices come from the owner's own list, and a code check rejects any number in the prose.
  • Asks the owner before anything is built, published or watched.

Machu

Market researcher · runs on its own cloud machine
  • Searches the web and map listings for nearby competitors.
  • Reads their pages and takes prices and quotes word for word.
  • Reports at least three priced competitors and the gap the business can fill.
  • After the owner agrees, sets up a monitor on the competitors' pages.

Angkor

Website builder · runs on its own cloud machine
  • Builds the business's page from the approved brief and the owner's own item list.
  • Uploads a preview for Petra to check and the owner to see.
  • Publishes the site at business.10squads.com only after the owner approves.
  • Holds no publishing key. Preview and publish go through the tensquads app.

How they talk

One message bus per business. Every step is an event on it: a Task, a Result, an Approval or an Escalation. The owner sees the agents' updates and questions in the chat.

Agents pull their work. Machu and Angkor ask the app for their next task and send their results back. They never talk to each other directly. Petra sits between them.

Every yes is recorded. When the owner approves, the app records a mandate: a fingerprint of exactly what was approved, valid for 24 hours. Angkor refuses to build or publish anything that does not match it.

Where it stands. The loop ran end to end on real machines on 7 November, up to the publish question, which was declined on purpose. Research passes its check in about one run in three. The watch step is built but has not run live yet.
